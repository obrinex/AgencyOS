# Security Policy

**Obrinex** — Effective Date: 26 July 2026

## 1. Scope
This policy describes the practical security measures Obrinex applies to protect client data and delivered systems. Obrinex does not currently hold formal third-party security certifications (such as SOC 2 or ISO 27001); the measures below reflect our actual current practice.

## 2. Access Control
Access to client data and systems is limited to personnel and authorized AI agents who need it to deliver or support the relevant engagement, using role-based access controls within our internal platform.

## 3. Encryption
Data in transit is protected using standard TLS encryption. Data at rest is protected using the native encryption provided by our infrastructure providers, including MongoDB Atlas.

## 4. Backups
Backups of client data and systems are performed every 7 days.

## 5. Incident Response
In the event of a suspected or confirmed security incident, Obrinex will investigate promptly and notify affected clients **within 48 hours** of becoming aware of the incident, describing what is known, what is being done, and any action the client should take.

## 6. Data Minimization
Personal data belonging to a client's own customers is retained only for the duration of the active security and maintenance period and is removed from Obrinex's systems upon proper handover, consistent with the Privacy Policy and DPA.

## 7. Sub-processor Security
Where Obrinex relies on third-party providers (see the DPA for the full list), we select providers with reasonable industry-standard security practices, while recognizing that some elements of security depend on those providers' own controls.

## 8. No Certifications Currently Held
Obrinex does not currently hold SOC 2, ISO 27001, or equivalent formal security certifications. This policy will be updated if that changes.

## 9. Reporting a Security Concern
Security concerns can be reported to support@obrinex.space.

## 10. Changes
This policy may be updated from time to time as our practices evolve. The most recently published version applies.
